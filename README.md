# Mohammad Anzar Akhtar — Portfolio

Personal portfolio for **Mohammad Anzar Akhtar**, an AI/ML Engineer & Full-Stack Developer shipping projects end-to-end — from deep learning model training to responsive, security-hardened deployed applications.

## About

This portfolio showcases my work across:
- **CampusConnect:** 29-route Next.js 15 + Supabase student collaboration platform with college-scoped RLS policies, atomic RPCs, and GSAP/R3F motion UI.
- **CI-MRGS:** Deep learning framework for multi-modal brain tumor segmentation on BraTS 2024 using Attention U-Net and Focal Tversky + Boundary loss.
- **AIOS:** Personal AI Operating System in Python with unidirectional layered architecture, state machine dispatch, and typed local event bus.
- **EcoPackAI:** AI packaging sustainability scoring engine shipped during my Infosys Full Stack Internship.

## Tech Stack

- **Framework:** Next.js 15 (App Router, React 19)
- **Styling:** Tailwind CSS, Geist Sans & Geist Mono fonts
- **Icons & Motion:** Lucide Icons, React Icons, Framer Motion
- **Theme:** Dark / Light mode via `next-themes`

## Local Development
