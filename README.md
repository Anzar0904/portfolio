## Deployment

The site is deployed on Vercel from the `master` branch of this repository.

When a final custom domain is added, set this environment variable in Vercel and redeploy:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com
```

This keeps metadata, sitemap, and robots URLs aligned with the production domain.

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
```

Static PDFs, resumes, logos, and project assets are served from the `public` directory.
